1. Formulas to know

Problem 1(a). Derivative and graph of $\sin^{-1}(x)$.

Problem 1(b). State the Inverse Function Theorem.

2. Logarithmic differentiation

Problem 2(a). Find $y'$ if $y=x^{\sqrt{x}}$.

Problem 2(b). Find $y'$ if $y=(\sin x)^{\sin x}$.

Problem 2(c). Find $y'(0)$ if $y=\frac{(x+1)^4e^x}{\sqrt{1+3x}}$.

3. Derivatives of logarithms

Problem 3(a). Find $y$ if $y'=\frac{\sin(x)}{\cos(x)}$.

Problem 3(b). Find the domain and range of $f(x)=\ln(\sqrt{9-e^x})$.

Problem 3(c). Let $f(x)=3-e^{-x}$. Find the domain and range of $f$, find $f^{-1}(x)$, and state the domain and range of $f^{-1}$. Does the graph of $f$ have a horizontal asymptote?

Problem 3(d). Find $y'(1)$ if $y=3^x\log_3(x)$.

4. Inverse trig functions

Problem 4(a). Prove the identity $\frac{d}{dx}\sec^{-1}(x)=\frac{1}{x\sqrt{x^2-1}}$ (ignore domain issues).

Problem 4(b). Find $y$ if $y'=\frac{x^2}{\frac19+x^6}$.

Problem 4(c). Find the equation of the tangent line to $y=2\tan^{-1}(x^2)$ at $x=1$.

Problem 4(d). Write $\cos(\tan^{-1}(x/2))$ as an algebraic function of $x$.

Problem 4(e). Find $y$ if $y'=\frac{x}{\sqrt{1-x^4}}$.

5. Hyperbolic functions

Problem 5(a). Find $\cosh^{-1}(2)$.

Problem 5(b). Evaluate $\lim_{x\to\infty}\coth x$.

Problem 5(c). Prove that the derivative of $\tanh x$ is $\operatorname{sech}^2x$.

Problem 5(d). Find $y'$ if $y=\tan^{-1}(\sinh x)$, and simplify.

Problem 5(e). Evaluate $\int_{-\ln3}^{\ln3}\cosh x\,dx$.

6. Inverse Function Theorem

Problem 6(a). Show $f(x)=x+x^3+2x^5$ is 1-1, then find the derivative of $f^{-1}$ at $(4,f^{-1}(4))$.

Problem 6(b). $f(x)=5x+2\sin x+2\cos x$, at $(2,f^{-1}(2))$.

Problem 6(c). Let $f(x)=x+e^x$. Find the equation of the tangent line to the graph of $f^{-1}$ at $x=1$.

Problem 6(d). Let $f(x)=2x^3+\ln x+\sin(\pi x)$ for $x>0$ (assume $f$ is 1-1). Find the slope of the tangent line to the graph of $f^{-1}$ at $x=2$.

Problem 7(d). $\lim_{x\to1^-}\frac{\ln x}{\cos^{-1}(x)}$

Problem 7(e). $\lim_{x\to\infty}x\left(\frac{\pi}{2}-\tan^{-1}(2x)\right)$

Problem 7(f). $\lim_{x\to\infty}\sin^{-1}\left(\frac{e^x}{2e^x+1}\right)$

Problem 7(g). $\lim_{x\to\infty}\frac{\cosh(\ln x)}{x}$

14. Numerical integration

Problem 14(a). $\int_0^1(x^3-3x^2+2x+1)\,dx$: over or under estimates, then $M_4$ and $T_4$.

Problem 14(b). Use the trapezoid rule with $n=3$ to approximate $\int_0^32^x\,dx$ in exact form.

Problem 14(c). How large must $n$ be so that the trapezoid rule approximates $\int_1^2\frac{dx}{x}$ with error less than $10^{-4}$?

15. Sequences

Problem 15(a). If an alternating sequence converges, what must it converge to?

Problem 15(b). Write $\{-\frac18,\frac1{27},-\frac1{64},\frac1{125},\dots\}$ as a function of $n$.

Problem 15(c). Monotonic? Bounded? $a_n=1+\frac{(-1)^n}{n}$ and $b_n=\frac{n}{n+1}$ ($n\ge1$).

Problem 15(d). Show that $\lim_{n\to\infty}\frac{3^n}{n!}=0$.

16. Test for Divergence (TFD)

Problem 16(a). $\sum_{n=1}^\infty\frac{(-1)^nn}{n+1}$

Problem 16(b). $\sum_{n=0}^\infty\frac{n^2+1}{6n^2+6n+1}$

Problem 16(c). Can you use the TFD on $\sum_{n=2}^\infty\frac{1}{n^2}$?

Problem 16(d). $\sum_{n=1}^\infty2^{1/n}$

Problem 16(e). Suppose $b_n>0$ and $\sum b_n$ converges. What does the TFD say about $\sum\frac{1}{b_n}$?

17. Telescoping series

Problem 17(a). $\sum_{n=2}^\infty\frac{1}{n^2-1}$

Problem 17(b). $\sum_{n=1}^\infty\left[\tan^{-1}(n+2)-\tan^{-1}(n)\right]$

Problem 17(c). $\sum_{n=1}^\infty\left[f(n)-f(n+1)\right]$, where $\lim_{n\to\infty}f(n)=L$

Problem 17(d). $\sum_{n=1}^\infty\left[f(n)-f(n+k)\right]$, $k$ a positive integer, $\lim f(n)=L$

Problem 17(e). Determine if $\sum_{n=1}^\infty\ln\left(1+\frac1n\right)$ converges or diverges by writing out its partial sums.

29. Approximations and error bounds

Problem 29(a). Approximate $\int_0^{0.1}\frac{dx}{1+x^4}$ to within $10^{-6}$.

Problem 29(b). Use $p_3(x)$ to approximate $\tan^{-1}(x)$ near $0$, and bound the error at $x=\frac12$ with ASE.

Problem 29(c). Bound the same error with Taylor's Inequality, bounding $|f^{(4)}(x)|$ on $[0,\frac12]$, where $f(x)=\tan^{-1}(x)$.

Problem 29(d). $f(x)=\sum_{n=2}^\infty5n(n-1)x^n$: parts (i) to (vi).

Problem 29(e). How many terms of $\sum_{n=0}^\infty\frac{(-1)^n}{n!}$ are needed to approximate its sum to within $0.001$?

Problem 29(f). $f(x)=e^x$: find $T_3(x)$ and bound $|f(x)-T_3(x)|$ for $-1\le x\le1$.

Problem 29(g). Approximate $\int_0^1e^{-x^2}\,dx$ to within $0.01$ (use ASE).

30. Complex numbers

31. Differential equations

Problem 31(a). Show that $y=Ce^{x^2}$ solves $y'=2xy$ for every constant $C$. Find the solution with $y(0)=3$.

Problem 31(b). Sketch the direction field of $y'=x+y$ at the nine points with $x,y\in\{-1,0,1\}$. Along which line are the slopes $0$? Sketch the solution through $(0,0)$.

Problem 31(c). Find the equilibrium solutions of $y'=y^2-4$ and decide whether nearby solutions move toward or away from each.

Problem 31(d). Euler's method with $h=0.5$ for $y'=x+y$, $y(0)=1$, to approximate $y(1)$. Over or under estimate?

Problem 31(e). Euler's method with $h=-1$ for $y'=y-x$, $y(1)=3$, to approximate $y(-1)$.

Problem 31(f). Solve $\frac{dy}{dx}=xy^2$, $y(0)=1$. On what interval is the solution defined?

Problem 31(g). Solve $\frac{dy}{dx}=e^{x-y}$, $y(0)=\ln2$.

Problem 31(h). Solve $\frac{dy}{dt}=3y-6$, $y(0)=5$.

Problem 31(i). Bacteria grow at a rate proportional to size, from $200$ cells to $600$ in $2$ hours. Find $P(t)$ and when $P=5400$.

Problem 31(j). Logistic: $\frac{dP}{dt}=0.5P\left(1-\frac{P}{1000}\right)$, $P(0)=200$. Carrying capacity, equilibria, growth, and $P(t)$.
