Chapter 3 · Applications of Differentiation

← previousoutlinenext →

This chapter is about what the derivative tells us about the function. The sign of $f'$ says where $f$ rises and falls, the sign of $f''$ says which way it bends, and the zeros of $f'$ locate the highest and lowest points. These facts solve optimization problems and let us sketch graphs by hand. The chapter ends with antiderivatives, which reverse differentiation.

3.1 Maximum and Minimum Values

ConceptLet $c$ be a number in the domain $D$ of $f$. Then $f(c)$ is the

  • absolute maximum value of $f$ on $D$ if $f(c) \ge f(x)$ for all $x$ in $D$, and the absolute minimum if $f(c) \le f(x)$ for all $x$ in $D$,
  • local maximum value if $f(c) \ge f(x)$ for all $x$ near $c$ (in some open interval containing $c$), and local minimum if $f(c) \le f(x)$ for all $x$ near $c$.

Maximum and minimum values together are extreme values. A local extreme value is compared only with nearby values. An absolute extreme value is compared with every value on the domain.

Extreme Value Theorem
If $f$ is continuous on a closed interval $[a, b]$, then $f$ attains an absolute maximum value $f(c)$ and an absolute minimum value $f(d)$ at some numbers $c$ and $d$ in $[a, b]$.

Why both hypotheses. $f(x) = x$ on the open interval $(0, 1)$ has no largest value (its values approach $1$ but never reach it). $f(x) = 1/x$ for $x \neq 0$, $f(0) = 0$, on $[-1, 1]$ is discontinuous at $0$ and unbounded. A closed interval and a continuous function rule out both examples.

Fermat's Theorem
If $f$ has a local maximum or minimum at $c$, and $f'(c)$ exists, then $f'(c) = 0$.

Why. At a local maximum, secant slopes to points on the right are $\le 0$ (the graph is not higher there) and to points on the left are $\ge 0$. The common limit $f'(c)$ is both $\le 0$ and $\ge 0$, so it is $0$. Picture: the tangent at a peak is horizontal.

A critical number of $f$ is a number $c$ in the domain of $f$ with $f'(c) = 0$ or $f'(c)$ undefined. Fermat's Theorem says that if $f$ has a local extreme value at $c$ and $f'(c)$ exists, then $f'(c) = 0$, so every local extreme value occurs at a critical number.

Warning

The converse of Fermat's Theorem is false. $f(x) = (x - 1)^3$ has $f'(1) = 0$ but no maximum or minimum at $1$ (it is increasing). And an extremum can occur where $f'$ does not exist: $f(x) = x^{2/3}$ has a minimum at $0$, a cusp, with $f'(0)$ undefined. A critical number is only a candidate for an extremum.

The Closed Interval Method. To find the absolute maximum and minimum values of a function $f$ that is continuous on a closed interval $[a, b]$:

  1. Find the values of $f$ at the critical numbers of $f$ in $(a, b)$.
  2. Find the values $f(a)$ and $f(b)$ at the endpoints.
  3. The largest value from steps 1 and 2 is the absolute maximum value, and the smallest is the absolute minimum value.

Why it works. Since $f$ is continuous on $[a, b]$, the Extreme Value Theorem says the absolute maximum and minimum values exist. An extreme value attained at a number $c$ in $(a, b)$ is a local extreme value, so Fermat's Theorem gives $f'(c) = 0$ if $f'(c)$ exists. Either way $c$ is a critical number. An extreme value not attained in $(a, b)$ occurs at an endpoint. So the list of candidates is complete.

Example. $f(x) = x^3 - 3x^2 + 1$ on $[-\tfrac12, 4]$. $f'(x) = 3x^2 - 6x = 3x(x - 2)$, so the critical numbers are $0$ and $2$. The values are $f(-\tfrac12) = \tfrac18$, $f(0) = 1$, $f(2) = -3$, $f(4) = 17$. The absolute maximum is $f(4) = 17$ and the absolute minimum is $f(2) = -3$.

The absolute maximum depends on the interval. $f(x) = x^3 - 3x^2 + 1$ on $[-1, b]$. For small $b$ the absolute maximum is at the critical number $0$. Once $b > 3$ it is at the right endpoint. The critical number $2$ is a candidate only when it lies inside the interval.

3.2 The Mean Value Theorem

Rolle's Theorem
Suppose $f$ is continuous on $[a, b]$, differentiable on $(a, b)$, and $f(a) = f(b)$. Then there is a number $c$ in $(a, b)$ with $f'(c) = 0$.

Why. Since $f$ is continuous on $[a, b]$, the Extreme Value Theorem says $f$ has an absolute maximum and an absolute minimum on $[a, b]$. If both are at the endpoints, $f$ is constant and $f' = 0$ on $(a, b)$. Otherwise one of them is attained at a number $c$ in $(a, b)$, and since $f'(c)$ exists, Fermat's Theorem gives $f'(c) = 0$.

Mean Value Theorem (MVT)
Suppose $f$ is continuous on $[a, b]$ and differentiable on $(a, b)$. Then there is a number $c$ in $(a, b)$ with $$f'(c) = \frac{f(b) - f(a)}{b - a}.$$

Picture. Somewhere between $a$ and $b$ the tangent line is parallel to the secant line through $(a, f(a))$ and $(b, f(b))$. This is the picture of Rolle's Theorem, tilted so that the secant is no longer horizontal. Motion. If a car's average velocity over a trip is $60$ mph, then at some instant its speedometer read exactly $60$.

Tangent parallel to secant. $f(x) = x^3 - 3x$ on $[-2, 2.5]$ has secant slope $2.25$. Slide $c$: the tangent turns yellow where $f'(c) = 3c^2 - 3 = 2.25$, at $c = \pm\sqrt{1.75}$. There can be more than one such $c$.

Example. $f(x) = x^3 - x$ on $[0, 2]$. The secant slope is $\dfrac{6 - 0}{2 - 0} = 3$, and $f'(c) = 3c^2 - 1 = 3$ gives $c = \tfrac{2}{\sqrt 3}$, which is in $(0, 2)$.

Consequences.

  • If $f'(x) = 0$ for all $x$ in an interval $(a, b)$, then $f$ is constant on $(a, b)$. (For any $x_1 < x_2$ there, the MVT applied to $f$ on $[x_1, x_2]$ gives $f(x_2) - f(x_1) = f'(c)(x_2 - x_1) = 0$.)
  • If $f'(x) = g'(x)$ for all $x$ in $(a, b)$, then $f - g$ is constant on $(a, b)$: $f(x) = g(x) + C$.
  • Bounds: if $f(0) = 1$ and $f'(x) \le 4$ for all $x$, then the MVT applied to $f$ on $[0, 3]$ gives $f(3) - f(0) = 3f'(c) \le 12$ for some $c$ in $(0, 3)$, so $f(3) \le 13$.
Warning

Check the hypotheses. $f(x) = |x|$ on $[-1, 1]$ has $f(-1) = f(1)$ but $f'(c) = 0$ nowhere, since $f$ is not differentiable at $0$. The theorems guarantee a $c$ only when $f$ is continuous on the closed interval and differentiable on the open one.

3.3 How Derivatives Affect the Shape of a Graph

Shape$f$ is increasing on an interval if $f(x_1) < f(x_2)$ for every pair of numbers $x_1 < x_2$ in the interval, and decreasing on the interval if $f(x_1) > f(x_2)$ for every such pair.

Increasing/Decreasing Test. If $f'(x) > 0$ for every $x$ in an interval, then $f$ is increasing on that interval. If $f'(x) < 0$ for every $x$ in an interval, then $f$ is decreasing on that interval. Why. For $x_1 < x_2$ in the interval, the MVT applied to $f$ on $[x_1, x_2]$ gives $f(x_2) - f(x_1) = f'(c)(x_2 - x_1)$ for some $c$ between $x_1$ and $x_2$, and this has the sign of $f'(c)$.

First Derivative Test. Let $c$ be a critical number of a continuous $f$.

  • If $f'$ changes from positive to negative at $c$, then $f$ has a local maximum at $c$.
  • If $f'$ changes from negative to positive at $c$, then $f$ has a local minimum at $c$.
  • If $f'$ has the same sign on both sides of $c$, then $f$ has no local extremum at $c$.

Picture. Increasing then decreasing gives a peak, and decreasing then increasing gives a valley.

Concavity. $f$ is concave upward on an interval if its graph lies above all of its tangent lines there, and concave downward if the graph lies below all of its tangent lines there. An inflection point is a point $(c, f(c))$ on a continuous curve where the concavity changes (from upward to downward or the reverse).

Concavity Test. If $f''(x) > 0$ for every $x$ in an interval, then $f$ is concave upward on that interval. If $f''(x) < 0$ for every $x$ in an interval, then $f$ is concave downward on that interval. Why. $f'' > 0$ means $f'$ is increasing, so the tangent slopes keep growing, and the graph bends upward, away from each tangent line.

Concavity and tangent lines. $f(x) = x^3 - 3x$ has $f''(x) = 6x$. On the green part ($x > 0$) each tangent lies below the graph, on the pink part ($x < 0$) above it. At the inflection point $(0, 0)$ the tangent crosses the graph.

Second Derivative Test. Suppose $f''$ is continuous near $c$ and $f'(c) = 0$. If $f''(c) > 0$, $f$ has a local minimum at $c$ (concave up, a valley). If $f''(c) < 0$, $f$ has a local maximum at $c$. If $f''(c) = 0$, the test is inconclusive.

Example. $f(x) = x^4 - 4x^3$. $f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3)$, so the critical numbers are $0$ and $3$. Since $4x^2 \ge 0$, the sign of $f'$ is the sign of $x - 3$: $f$ is decreasing on $(-\infty, 3)$ and increasing on $(3, \infty)$. So $f(3) = -27$ is a local (in fact absolute) minimum and there is no extremum at $0$. $f''(x) = 12x^2 - 24x = 12x(x - 2)$, so $f$ is concave upward on $(-\infty, 0)$ and $(2, \infty)$ and concave downward on $(0, 2)$, with inflection points $(0, 0)$ and $(2, -16)$. Since $f''(0) = 0$, the Second Derivative Test is inconclusive at $0$, but the First Derivative Test applies.

Warning

$f''(c) = 0$ does not make $(c, f(c))$ an inflection point. $f(x) = x^4$ has $f''(0) = 0$ but is concave upward on both sides. Check that $f''$ changes sign. Also, increasing/decreasing and concavity are properties of intervals of $x$, so answer with intervals, not points.

3.4 Limits at Infinity; Horizontal Asymptotes

Concept$\displaystyle\lim_{x \to \infty} f(x) = L$ means $f(x)$ can be made as close to $L$ as we like by taking $x$ large enough. Similarly, $\lim_{x \to -\infty} f(x) = L$ means the same with $x$ large and negative. The line $y = L$ is a horizontal asymptote of $y = f(x)$ if $\lim_{x \to \infty} f(x) = L$ or $\lim_{x \to -\infty} f(x) = L$.

Basic fact. If $r > 0$, then $\displaystyle\lim_{x \to \infty}\frac{1}{x^r} = 0$ (and the same holds as $x \to -\infty$ when $x^r$ is defined). Why. Dividing $1$ by a very large number gives a very small one.

Rational functions. Divide numerator and denominator by the highest power of $x$ in the denominator, then use the basic fact.

$\displaystyle\lim_{x \to \infty}\frac{3x^2 - x}{5x^2 + 2} = \lim_{x \to \infty}\frac{3 - 1/x}{5 + 2/x^2} = \frac{3}{5}.$

For a rational function, let $p$ be the degree of the numerator and $q$ the degree of the denominator. If $p < q$ the limit is $0$, if $p = q$ it is the ratio of the leading coefficients, and if $p > q$ it is $\infty$ or $-\infty$ (no horizontal asymptote). Why. For large $|x|$ each polynomial is dominated by its leading term.

A horizontal asymptote. $f(x) = \dfrac{2x^2 + 3x}{x^2 + 1}$ approaches $y = 2$ as $x \to \pm\infty$. Near the origin it crosses that line at $x = \tfrac23$.

Roots. Use $\sqrt{x^2} = |x|$, which is $x$ for $x > 0$ and $-x$ for $x < 0$. Example: for $x < 0$, $\dfrac{\sqrt{4x^2 + 1}}{x + 3} = \dfrac{|x|\sqrt{4 + 1/x^2}}{x(1 + 3/x)} = \dfrac{-\sqrt{4 + 1/x^2}}{1 + 3/x}$, so $\displaystyle\lim_{x \to -\infty}\frac{\sqrt{4x^2 + 1}}{x + 3} = -2$, while the limit as $x \to \infty$ is $2$.

Oscillation. $\lim_{x \to \infty}\sin x$ does not exist. But $\dfrac{\sin x}{x}$ is squeezed between $-\dfrac1x$ and $\dfrac1x$, so it approaches $0$.

Warning

A graph may cross a horizontal asymptote, as in the figure. An asymptote describes the behavior for large $|x|$ only. And $\infty - \infty$ is not $0$: rewrite first, e.g. $\sqrt{x^2 + x} - x = \dfrac{x}{\sqrt{x^2 + x} + x} \to \tfrac12$ as $x \to \infty$.

3.5 Curve Sketching

ChecklistTo sketch $y = f(x)$ by hand, find the following:

  1. Domain. The set where $f$ is defined.
  2. Intercepts. The $y$-intercept is $f(0)$, and the $x$-intercepts are the solutions of $f(x) = 0$.
  3. Symmetry. Check whether $f$ is even ($f(-x) = f(x)$, mirror in the $y$-axis) or odd ($f(-x) = -f(x)$, symmetric about the origin).
  4. Asymptotes. Find the vertical asymptotes (where a denominator is $0$ and the numerator is not) and the horizontal asymptotes (from $\lim_{x \to \pm\infty}$).
  5. Increasing/decreasing intervals come from the sign of $f'$, and local extrema from the First Derivative Test.
  6. Concavity comes from the sign of $f''$, which also locates the inflection points.
  7. Sketch. Plot the special points, draw the asymptotes, and connect them according to the increasing/decreasing and concavity information.

Example. $f(x) = \dfrac{x^2}{x^2 - 4}$.

  • The domain is $x \neq \pm 2$. The only intercept is $(0, 0)$. $f$ is even, so its graph is symmetric about the $y$-axis.
  • The vertical asymptotes are $x = \pm 2$. The horizontal asymptote is $y = 1$ (equal degrees, leading coefficients $1$ and $1$).
  • $f'(x) = \dfrac{2x(x^2 - 4) - x^2\cdot 2x}{(x^2 - 4)^2} = \dfrac{-8x}{(x^2 - 4)^2}$. So $f$ is increasing on $(-\infty, -2)$ and $(-2, 0)$ and decreasing on $(0, 2)$ and $(2, \infty)$, with local maximum $f(0) = 0$.
  • $f''(x) = \dfrac{8(3x^2 + 4)}{(x^2 - 4)^3}$. The numerator is positive for every $x$, so $f''$ has the sign of $(x^2 - 4)^3$, and $f$ is concave upward for $|x| > 2$ and downward for $|x| < 2$. There are no inflection points, since $x = \pm 2$ are not in the domain.
Sign charts

To find the sign of $f'$ (or $f''$), factor it, mark its zeros and undefined points on a number line, and test one number in each of the resulting intervals. The sign is constant on each interval because $f'$ can only change sign where it is $0$ or undefined: if $f'$ is continuous on an interval and takes both signs there, the IVT gives a number in that interval where $f'$ is $0$.

3.6 Optimization Problems

ApplicationAn optimization problem asks for the largest or smallest value of a quantity. The method is to write that quantity as a function of one variable on an interval, then apply 3.1 or 3.3.

  1. Draw a picture and name the quantities with variables.
  2. Write the quantity $Q$ to be maximized or minimized (the objective) in terms of the variables.
  3. Use the given conditions (the constraint) to write $Q$ as a function of one variable, and find that variable's domain.
  4. Find the absolute max or min of $Q$. On a closed interval use the Closed Interval Method. Otherwise use the First Derivative Test: if $Q$ has one critical number and $Q'$ changes sign there, then $Q$ has an absolute extremum there.
  5. Answer the question asked, with units.

Example (open box). From a $12$ by $12$ inch sheet, cut a square of side $x$ from each corner and fold up the sides. The box has base $(12 - 2x)$ by $(12 - 2x)$ and height $x$, so $V(x) = x(12 - 2x)^2$ for $0 \le x \le 6$. $V'(x) = (12 - 2x)^2 - 4x(12 - 2x) = (12 - 2x)(12 - 6x)$, which is $0$ at $x = 2$ and $x = 6$. The values are $V(0) = 0$, $V(2) = 128$, $V(6) = 0$. The largest box has $x = 2$ in and volume $128$ in³.

Open box volume. Small $x$ gives a flat box, large $x$ a tall thin one. The volume $V(x) = x(12 - 2x)^2$ peaks in between, at $x = 2$.

Example (a product). Find nonnegative numbers $x$ and $y$ with $x + y = 12$ that make $P = x y^2$ as large as possible. The constraint gives $x = 12 - y$, so $P(y) = (12 - y)y^2 = 12y^2 - y^3$ for $0 \le y \le 12$. $P'(y) = 24y - 3y^2 = 3y(8 - y)$ is $0$ at $y = 0$ and $y = 8$. The values are $P(0) = 0$, $P(8) = 256$, $P(12) = 0$. The maximum is $256$, at $y = 8$, $x = 4$.

Warning

A critical number is not automatically the answer. Verify that it gives a maximum (or minimum), by comparing with endpoints or by a derivative test, and make sure it is in the domain the picture allows.

3.7 Antiderivatives

BackwardA function $F$ is an antiderivative of $f$ on an interval $I$ if $F'(x) = f(x)$ for all $x$ in $I$.

Theorem
If $F$ is an antiderivative of $f$ on an interval $I$, then the most general antiderivative of $f$ on $I$ is $F(x) + C$, where $C$ is an arbitrary constant.

Why. If $G' = f = F'$ on $I$, then $G - F$ has derivative $0$ on $I$, and the consequence of the MVT in 3.2 says a function with derivative $0$ on an interval is constant there, so $G - F$ is constant on $I$. Picture: the graphs of all antiderivatives are vertical shifts of one another, with the same slope at each $x$.

A family of antiderivatives. The purple segments have slope $x^2 - 2x$ at each point. Every curve $F(x) = \tfrac{x^3}{3} - x^2 + C$ follows them. Fixing one value, such as $F(0)$, determines one curve.

Antiderivative table (read the derivative table backward, with $n \neq -1$):

$x^n \mapsto \dfrac{x^{n + 1}}{n + 1}, \quad \cos x \mapsto \sin x, \quad \sin x \mapsto -\cos x, \quad \sec^2 x \mapsto \tan x, \quad \sec x\tan x \mapsto \sec x,$

each plus $C$. Constant multiples factor out, and sums are antidifferentiated term by term. Check any antiderivative by differentiating it.

Example. The most general antiderivative of $f(x) = 6x^2 - \dfrac{3}{\sqrt x} + 4\sec^2 x$ is $F(x) = 2x^3 - 6\sqrt x + 4\tan x + C$. (Check: $\dfrac{d}{dx}(-6x^{1/2}) = -3x^{-1/2}$.)

Initial value problems. Given $f'$ and one value of $f$, find $f$. Example: $f'(x) = 2x + \cos x$, $f(0) = 4$. Then $f(x) = x^2 + \sin x + C$ and $0 + 0 + C = 4$, so $f(x) = x^2 + \sin x + 4$. Given $f''$, antidifferentiate twice with two constants: $f''(x) = 6x$, $f'(0) = 2$, $f(0) = 1$ give $f'(x) = 3x^2 + 2$ and $f(x) = x^3 + 2x + 1$.

Motion. Let $s$ be position, $v = s'$ velocity, and $a = v'$ acceleration. Then velocity is an antiderivative of acceleration and position is an antiderivative of velocity. A ball thrown up at $20$ m/s from height $5$ m, with $a = -10$ m/s², has $v(t) = -10t + 20$ and $s(t) = -5t^2 + 20t + 5$.

Warning

Do not forget $+ C$, and do not antidifferentiate a product or quotient factor by factor. There is no product rule for antiderivatives: an antiderivative of $(x^2 + 1)^2$ is not $\tfrac13(x^2 + 1)^3$ (differentiate that to see the extra factor $2x$). Expand first, $x^4 + 2x^2 + 1$, giving $\tfrac{x^5}{5} + \tfrac{2x^3}{3} + x + C$.

Worked example

A complete analysis. $f(x) = x^3 - 6x^2 + 9x$ on $[0, 4]$.
$f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$, so the critical numbers are $1$ and $3$. Sign chart: $f' > 0$ on $(0, 1)$, $f' < 0$ on $(1, 3)$, $f' > 0$ on $(3, 4)$. So $f$ has a local maximum $f(1) = 4$ and a local minimum $f(3) = 0$.
$f''(x) = 6x - 12$, negative for $x < 2$ and positive for $x > 2$, so $f$ is concave downward on $(0, 2)$ and upward on $(2, 4)$, with inflection point $(2, 2)$. The Second Derivative Test agrees: $f''(1) = -6 < 0$ (max) and $f''(3) = 6 > 0$ (min).
Closed Interval Method: $f(0) = 0$, $f(1) = 4$, $f(3) = 0$, $f(4) = 4$. The absolute maximum is $4$ (at $x = 1$ and $x = 4$) and the absolute minimum is $0$ (at $x = 0$ and $x = 3$).
MVT on $[0, 4]$: the secant slope is $\tfrac{4 - 0}{4} = 1$, and $3c^2 - 12c + 9 = 1$ gives $c = 2 \pm \tfrac{2}{\sqrt 3}$, both in $(0, 4)$.

Practice problems

  1. Find the absolute maximum and minimum values of $f(x) = x^3 - 12x + 1$ on $[-3, 5]$.
  2. Find the critical numbers of $f(x) = x^{2/3}(x - 5)$ and classify each.
  3. Verify that $f(x) = x^2 - 4x + 1$ satisfies the hypotheses of the MVT on $[0, 3]$ and find every $c$ guaranteed by the theorem.
  4. For $f(x) = x^4 - 8x^2$, find the intervals of increase and decrease, the local extrema, the intervals of concavity, and the inflection points.
  5. Find $\displaystyle\lim_{x \to \infty}\frac{4x^3 - x}{2x^3 + 7}$ and $\displaystyle\lim_{x \to -\infty}\frac{\sqrt{9x^2 + 1}}{2x - 1}$.
  6. Sketch $f(x) = \dfrac{x - 1}{x^2}$ using the checklist.
  7. An open box with a square base must have volume $32$ ft³. Find the dimensions that use the least material.
  8. Find $f$ if $f'(x) = 4x^3 - \sin x$ and $f(0) = 3$.

Strategies

Absolute vs local. For absolute extrema on a closed interval, use the Closed Interval Method (critical numbers and endpoints). For local extrema, use the First or Second Derivative Test at the critical numbers.

Finding critical numbers. Factor $f'$. Include numbers in the domain where $f'$ is undefined (e.g. where a fractional power has $0$ in the denominator of its derivative).

Sign charts. Mark where $f'$ (or $f''$) is $0$ or undefined, test one point in each interval, and read off the shape.

Choosing between the First and Second Derivative Tests. The Second Derivative Test is quick when $f''$ is easy to compute and nonzero at $c$. The First Derivative Test always works at a critical number and also handles points where $f'$ is undefined.

Limits at infinity. Divide by the highest power of $x$ in the denominator. With roots, remember $\sqrt{x^2} = |x|$, which matters as $x \to -\infty$.

Optimization. Draw a picture, write the objective and the constraint, reduce to a function of one variable with its domain, then verify the maximum or minimum.

Antiderivatives. Rewrite as a sum of powers and basic trig functions, antidifferentiate each term, add $C$, and check by differentiating. Use the given values to find the constants.
