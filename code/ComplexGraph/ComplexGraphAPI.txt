COMPLEXGRAPH
================================================================================

  makeComplexGraph
    INPUTS:  CGGraph, MutableFreeComplex
    OUTPUTS: ComplexGraph

  complexGraphFromMFC
    INPUTS:  MutableFreeComplex
    OUTPUTS: ComplexGraph

  mGrdComplexGraph is a child of ComplexGraph whose vertices carry a numeric
  multidegree (the exponent vector of the vertex monomial). Combinatorial
  ComplexGraph methods are inherited; methods that read the multigrading take an
  mGrdComplexGraph. Any constructor that labels its vertices returns one.

  makeMGrdComplexGraph
    INPUTS:  CGGraph, MutableFreeComplex
    OUTPUTS: mGrdComplexGraph

  getVertexMultidegree
    INPUTS:  mGrdComplexGraph, CGVertex   (or mGrdComplexGraph, ZZ, ZZ)
    OUTPUTS: List (exponent vector), or null if unweighted

  taylorComplexGraph
    INPUTS:  List of RingElement, Ring
    OUTPUTS: mGrdComplexGraph
    NOTES:   builds the differentials, vertex weights, and edges in parallel
             across allowableThreads; a hash subset-index gives O(1) face
             lookup. DiskComplex provides the disk-backed parallel variant.

  buildComplexGraph
    INPUTS:  CGGraph, MutableFreeComplex, Ring
    OUTPUTS: ComplexGraph

  buildTaylorVertices
    INPUTS:  List of RingElement, Ring
    OUTPUTS: List of CGVertex

  edgesFromMFCWithVertices
    INPUTS:  MutableFreeComplex, List of CGVertex
    OUTPUTS: List of CGEdge

  assignVertexLabels
    INPUTS:  MutableFreeComplex
    OUTPUTS: mGrdComplexGraph

  getCGGraph, getCGMFC, getCGRing
  getCGEdgeWeight   -- (ComplexGraph, CGEdge) => Thing
  setCGEdgeWeight   -- (ComplexGraph, CGEdge, Thing)

  syncGraphFromMFC  -- ComplexGraph => mGrdComplexGraph
  graphFromMFC      -- MFC => CGGraph

  reorderVerticesAtDegree
    INPUTS:  ComplexGraph, ZZ (degree), List (permutation)
    OUTPUTS: mGrdComplexGraph

  orderedTaylorMFC
    INPUTS:  List of RingElement, Ring
    OUTPUTS: MutableFreeComplex

================================================================================
MATCHING ALGORITHMS
================================================================================

  bmMatchingDown, greedyDown, bmMatchingUp, prunedMatching
    INPUTS:  ComplexGraph or CGGraph
    OUTPUTS: AcyclicMatching

  cubePrunedBetti
    INPUTS:  List of RingElement, Ring
    OUTPUTS: BettiTally
    OPTION:  ReturnMatching => false (default)
             when true, returns (BettiTally, List of {src, tgt})

  cubePrunedMatching
    INPUTS:  List of RingElement, Ring
    OUTPUTS: HashTable, keys "matching", "critical", "multidegree"
    A mcc-maximal matching on the subset cube, built bottom-up without the
    Taylor complex. Cells are generator subsets, multidegree is the lcm support.

  cubePrunedResolution
    INPUTS:  List of RingElement, Ring
    OUTPUTS: HashTable, keys "ranks", "badPrimes", "sccs"
    Minimal free resolution data of R/I read from the cube-pruning matching:
    Betti numbers over QQ, the primes where they jump, and the obstruction
    sccs with their integer cokernels. Tractable where the Taylor build is not.

  cubeMCCCells
    INPUTS:  ZZ (n), Function (supportOf), Thing (b)
    OUTPUTS: (bySize, degs, shift, indexOf)
    The subsets of {0..n-1} whose lcm support is the multidegree b, bucketed
    by size with a per-size index. Building block of cubePrunedResolution.

  cubeMCCComplex
    INPUTS:  (bySize, degs, shift, indexOf)   (output of cubeMCCCells)
    OUTPUTS: MutableFreeComplex   -- the mcc complex for one multidegree, over QQ

  cubePrunedResolutionPrimes
    List of small primes {2,3,5,7,11,13} tested for torsion in each scc.
