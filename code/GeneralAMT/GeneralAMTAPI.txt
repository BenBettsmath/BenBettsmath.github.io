  replacementAdjacency
    INPUTS: MutableFreeComplex, List (matching)
    OUTPUTS: HashTable

  isAcyclicMatching
    INPUTS: MutableFreeComplex, List
    OUTPUTS: Boolean

  greedyMorseMatching
    INPUTS: MutableFreeComplex
    OUTPUTS: List
    Morse, not maximal.

  bmMatrixMatching
    INPUTS: MutableFreeComplex
    OUTPUTS: List
    Maximal Morse.

  antidiagonalBinaryMatching
    INPUTS: MutableFreeComplex
    OUTPUTS: List
    Maximal Morse.

  mccMatching
    INPUTS: ComplexGraph
    OUTPUTS: List
    Maximal Morse, built mcc by mcc. Used by genAMTReduce(ComplexGraph).

  Matcher map.
    MFC: greedyMorseMatching (not maximal), bmMatrixMatching,
    antidiagonalBinaryMatching.
    ComplexGraph: mccMatching, bmMatchingDown, greedyDown, bmMatchingUp,
    prunedMatching.

================================================================================
USING WITH COMPLEXGRAPH
================================================================================

    needsPackage "ComplexGraph"
    needsPackage "GeneralAMT"
    R = QQ[x, y, z, w]
    G = {x*y, x*w, y*z, z*w}
    cg  = taylorComplexGraph(G, R)
    out = genAMTReduce getCGMFC cg

  "critByDeg" holds the surviving cells by MFC index. Recover monomial labels by
  vertex key.

    for k in sort keys out#"critByDeg" list
        for i in out#"critByDeg"#k list
            getVertexLabel findVertexByKey(getCGGraph cg, {k, i})
