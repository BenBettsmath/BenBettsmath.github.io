Nilpotent matrices

Prop. Nilpotent matrices. (D&F §12.3) For an $n \times n$ matrix $A$:
  • $A$ is nilpotent $\Leftrightarrow$ all eigenvalues are $0$ $\Leftrightarrow$ $\chi_A(x) = x^n$.
  • The nilpotency index $\nu(A) = \min\{k : A^k = 0\}$ satisfies $\nu(A) \leq n$ by Cayley-Hamilton.
  • $\nu(A)$ equals the size of the largest Jordan block in $A$. The block structure, not just the size of the matrix, determines how fast $A$ kills vectors.
Nilpotent operators are the most degenerate: all powers of eigenvalues are zero.
Example. The strict upper triangular $N$ with $1$s on the superdiagonal is maximally nilpotent: $N^n = 0$ but $N^{n-1} \neq 0$. Its index is $n$, the largest possible. It is a single $n \times n$ Jordan block.
Non-example. $\mathrm{diag}(1, 0)$ has eigenvalue $1$, so not nilpotent. The matrix $\mathrm{diag}(0, 0, N_2)$ with $N_2$ the $2 \times 2$ shift is nilpotent of index $2$, not $4$, because the largest Jordan block is size $2$.
Fun fact. Index equals largest Jordan block size. For the matrix $J_3(0) \oplus J_2(0)$ (direct sum of two Jordan blocks), $\chi = x^5$, but $m = x^3$. You need three powers, not five, because the $3 \times 3$ block is the largest. Index of nilpotency is the bottleneck: the biggest Jordan block dictates how many powers you need to zero everything.
