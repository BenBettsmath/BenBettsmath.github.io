Nilpotent matrices

Prop. Nilpotent matrices. (D&F §12.3) For an $n \times n$ matrix $A$:
  • $A$ is nilpotent $\Leftrightarrow$ all eigenvalues are $0$ $\Leftrightarrow$ $\chi_A(x) = x^n$.
  • The nilpotency index $\nu(A) = \min\{k : A^k = 0\}$ satisfies $\nu(A) \leq n$ by Cayley-Hamilton.
  • $\nu(A)$ equals the size of the largest Jordan block in $A$. So how fast $A$ kills everything depends on its block structure, not just on the size of the matrix.
The reason $\nu(A) \leq n$ is that $m_A$ divides $\chi_A = x^n$, so $m_A = x^k$ for some $k \leq n$.
Example. The strictly upper triangular $N$ with $1$s on the superdiagonal has $N^n = 0$ but $N^{n-1} \neq 0$, since each power pushes the $1$s one diagonal further up. Its index is $n$, the largest possible. It is a single $n \times n$ Jordan block.
Non-example. $\mathrm{diag}(1, 0)$ has eigenvalue $1$, so not nilpotent. The matrix $\mathrm{diag}(0, 0, N_2)$ with $N_2$ the $2 \times 2$ shift is nilpotent of index $2$, not $4$, because the largest Jordan block is size $2$.
Remark. Index equals largest Jordan block size. For the matrix $J_3(0) \oplus J_2(0)$ (direct sum of two Jordan blocks), $\chi = x^5$, but $m = x^3$. We only need three powers, not five, since $J_3(0)^3 = 0$ and $J_2(0)^2 = 0$ already. Each block dies on its own schedule, so the biggest one decides when everything is zero.
