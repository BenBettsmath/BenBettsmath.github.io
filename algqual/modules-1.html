Free, torsion, and finitely generated modules

Def. Module. (D&F §10.1) A left $R$-module $M$ is an abelian group with an action $R \times M \to M$, $(r, m) \mapsto rm$, satisfying $1m = m$, $(rs)m = r(sm)$, and bilinearity: $(r+s)m = rm + sm$, $r(m+n) = rm + rn$. So a module is the same thing as a vector space, except the scalars come from a ring instead of a field. $M$ is free of rank $n$ if $M \cong R^n$, torsion if every element is killed by some nonzero $r \in R$, and finitely generated if a finite subset generates $M$.
Examples. Vector spaces are $F$-modules, abelian groups are $\mathbb{Z}$-modules, ideals $I \leq R$ are $R$-modules, and $R/I$ is an $R$-module.
Non-example. $\mathbb{Q}$ is a $\mathbb{Z}$-module but not finitely generated: any finite subset $\{a_1/b_1, \ldots, a_n/b_n\}$ generates only fractions with denominators dividing $\mathrm{lcm}(b_i)$, so for example $1/(2\,\mathrm{lcm}(b_i))$ is never in the span.
Remark. The annihilator is always an ideal. (D&F §10.1) The set $\mathrm{ann}_R(M) = \{r \in R : rm = 0 \text{ for all } m \in M\}$ is an ideal of $R$, since if $r$ and $r'$ kill everything then so do $r + r'$ and $sr$ for any $s \in R$. For $M = R/I$ the annihilator is $I$ itself: $r$ kills $R/I$ iff $r \in I$. For direct sums, $r$ kills $M_1 \oplus M_2$ iff it kills both, so $\mathrm{ann}(M_1 \oplus M_2) = \mathrm{ann}(M_1) \cap \mathrm{ann}(M_2)$.
