Sylow theorems

Thm (Sylow). (D&F §4.5, Thm. 18) Let $|G| = p^a m$ with $p \nmid m$.
  1. Existence: Sylow $p$-subgroups (subgroups of order $p^a$) exist.
  2. Conjugacy: All Sylow $p$-subgroups are conjugate. Any $p$-subgroup nests in some Sylow $p$-subgroup.
  3. Count: The number $n_p$ of Sylow $p$-subgroups satisfies $n_p \equiv 1 \pmod{p}$ and $n_p \mid m$. Most Sylow problems come down to using these two conditions to cut down the list of possible values of $n_p$.
Prop. More Sylow facts. (D&F §4.5)
  • $P \in \mathrm{Syl}_p(G)$ and $P \leq H \leq G$ implies $P \in \mathrm{Syl}_p(H)$. (This is just because $p^a$ is still the largest power of $p$ dividing $|H|$.)
  • $N_G(P)/C_G(P) \hookrightarrow \mathrm{Aut}(P)$, since $N_G(P)$ acts on $P$ by conjugation and $C_G(P)$ is exactly the kernel. So $|N_G(P)/C_G(P)|$ divides $|\mathrm{Aut}(P)|$, and since $n_p = [G:N_G(P)]$ this can rule out some values of $n_p$.
  • If $n_p = 1$ for all primes $p \mid |G|$, then $G \cong P_1 \times \cdots \times P_k$ where $P_i$ is the unique Sylow $p_i$-subgroup. (This is because the Sylow subgroups are then all normal, they only share the identity, and their orders multiply to $|G|$.)
Note. Proving $G$ is not simple.
  1. List $n_p$ candidates for each $p \mid |G|$ using $n_p \equiv 1 \pmod p$, $n_p \mid m$.
  2. If $n_p = 1$ for some $p$, the unique Sylow $p$-subgroup is normal, so $G$ is not simple (as long as $|G|$ isn't a power of $p$).
  3. Else count elements: each Sylow $p$-subgroup (if cyclic of prime order) contributes $p-1$ nonidentity elements of order $p$. Two different subgroups of order $p$ only share the identity, so these elements are all different. If $n_p(p-1) + (\text{other elements}) > |G|$ then we've counted too many elements, so $n_p$ can't be that large.
  4. If $n_p$ is small, let $G$ act on its $n_p$ Sylow $p$-subgroups by conjugation. This gives $G \to S_{n_p}$, which can't be injective when $n_p! < |G|$, and its kernel isn't all of $G$ since the action moves the Sylow subgroups around. So the kernel is a nontrivial proper normal subgroup.
  5. Use automorphism constraint: $N_G(P)/C_G(P) \hookrightarrow \mathrm{Aut}(P)$ implies $|N_G(P)/C_G(P)| \mid |\mathrm{Aut}(P)|$, ruling out large $n_p$.
Computation. Worked Sylow examples.

$|G| = pq$, $p < q$. $n_q \equiv 1 \pmod q$ and $n_q \mid p$, so $n_q \in \{1, p\}$, and $n_q = p$ is impossible since $p < q$ means $p \not\equiv 1 \pmod q$. So $n_q = 1$. If also $p \nmid q-1$ then $n_p = q$ is impossible for the same reason, so $n_p = 1$. Then both Sylow subgroups are normal and $G \cong \mathbb{Z}/p \times \mathbb{Z}/q \cong \mathbb{Z}/pq$.

$|G| = 30$. $n_5 \in \{1, 6\}$, $n_3 \in \{1, 10\}$. If both are $>1$ then there are $6 \cdot 4 = 24$ elements of order $5$ and $10 \cdot 2 = 20$ of order $3$, which is $44 > 30$ elements. So $n_3 = 1$ or $n_5 = 1$.

$|G| = 56 = 2^3 \cdot 7$. $n_7 \in \{1, 8\}$. If $n_7 = 8$ then there are $8 \cdot 6 = 48$ elements of order $7$, leaving only $8$ other elements. That's exactly enough room for one Sylow $2$-subgroup of order $8$, so $n_2 = 1$.

$|G| = 80 = 2^4 \cdot 5$. $n_5 \in \{1, 16\}$. If $n_5 = 16$ then there are $16 \cdot 4 = 64$ elements of order $5$, leaving only $16$ other elements, which is exactly enough room for one Sylow $2$-subgroup of order $16$. So $n_2 = 1$.

$|G| = 132 = 4 \cdot 3 \cdot 11$. $n_{11} \in \{1, 12\}$. If $n_{11} = 12$ then there are $12 \cdot 10 = 120$ elements of order $11$, leaving $12$. That's too few to fit more than one Sylow $2$-subgroup and more than one Sylow $3$-subgroup at the same time. So one of those is normal.

$|G| = p^2 q$ with $p > q$. $n_p \mid q$ and $n_p \equiv 1 \pmod p$. With $p > q$, only $n_p = 1$ works.
