Normal subgroups and the isomorphism theorems

Def. Normal subgroup. (D&F §3.1) $H \trianglelefteq G$ iff $gHg^{-1} = H$ for every $g \in G$. This is exactly what we need for the coset space $G/H$ to be a group, since multiplying cosets by $(aH)(bH) = abH$ only makes sense if the answer doesn't depend on which $a$ and $b$ we picked. Normal doesn't mean the elements of $H$ commute with everything. It means conjugating $H$ by anything lands back in $H$, even if the individual elements get moved around inside $H$.
Remark. Every kernel is normal, and every normal subgroup is a kernel, namely of the quotient map $G \to G/H$. So normal subgroups and kernels are really the same thing. This is also usually the easiest way to check normality, since if we can find a homomorphism with kernel $H$ then we're done. (D&F §3.1)
Example. $A_n \trianglelefteq S_n$ (kernel of the sign map), and $Z(G) \trianglelefteq G$ always.
Non-example. $\langle (1\,2) \rangle$ is not normal in $S_3$. Conjugating by $(1\,2\,3)$ turns $(1\,2)$ into $(2\,3)$, which isn't in the subgroup. This is because conjugating a permutation just relabels the points it moves, so the subgroup generated by one transposition is never normal in $S_n$ for $n \geq 3$.
Remark. Normality is not transitive. In $D_8$ take a reflection $s$. Then $\langle s \rangle \trianglelefteq \langle s, r^2 \rangle \trianglelefteq D_8$, but $\langle s \rangle$ is not normal in $D_8$ since $rsr^{-1} = sr^{-2} \notin \langle s \rangle$. Each step is normal because it has index 2, but that doesn't carry through the whole chain. This shows up on quals a lot. (D&F §3.1)
Thm. The four isomorphism theorems. (D&F §3.3)
  1. First: $G/\ker\phi \cong \mathrm{im}\,\phi$ for any homomorphism $\phi$. This is the one we use the most. Almost every "identify this quotient" problem comes down to finding the right $\phi$ to apply it to.
  2. Second (diamond): $H/(H \cap N) \cong HN/N$ when $N \trianglelefteq G$ and $H \leq G$. If we draw the diamond of subgroups $H \cap N \leq H, N \leq HN$, then the two parallel sides give isomorphic quotients.
  3. Third: $(G/N)/(H/N) \cong G/H$ when $N \trianglelefteq H \trianglelefteq G$. Quotients of quotients cancel like fractions, which makes this one easy to remember.
  4. Fourth (lattice): Subgroups of $G/N$ correspond bijectively with subgroups of $G$ containing $N$, preserving containment, normality, and index. So the subgroups of $G/N$ are just the subgroups of $G$ sitting above $N$, with $N$ collapsed down to the identity.
Prop. Tests for normality. (D&F §3.2, 4.2)
  • $[G:H] = 2 \Rightarrow H \trianglelefteq G$. This is because the left cosets and the right cosets are both just $H$ and everything else, so $gH = Hg$ for every $g$.
  • More generally, if $[G:H] = p$ is the smallest prime dividing $|G|$, then $H \trianglelefteq G$. The index 2 case is this with $p = 2$.
  • $Z(G)$ and $[G,G]$ are always normal, and so is any subgroup of $Z(G)$. This is because conjugation fixes every element of $Z(G)$, and sends commutators to commutators.
  • $H, K \trianglelefteq G \Rightarrow H \cap K \trianglelefteq G$ and $HK \trianglelefteq G$.
Remark. The order of $HK$. (D&F §3.2) For finite subgroups, $|HK| = \dfrac{|H|\,|K|}{|H \cap K|}$ whether or not $HK$ is a subgroup. This is because each element of $HK$ can be written as $hk$ in exactly $|H \cap K|$ ways. And $HK$ is a subgroup iff $HK = KH$, which is automatic when either one is normal.
Prop. Commutator subgroup. (D&F §5.4) $[G,G]$ is generated by the commutators $[x,y] = xyx^{-1}y^{-1}$. Since $xy = [x,y]\,yx$, the commutators measure how far $G$ is from being abelian, and $[G,G]$ is the smallest normal subgroup with abelian quotient. So $G/[G,G]$, the abelianization, is the largest abelian quotient of $G$, and any homomorphism from $G$ to an abelian group factors through it.
